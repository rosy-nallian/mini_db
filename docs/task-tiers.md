# 任务分级清单（P0 必做 / P1 进阶 / P2 扩展）

> 本文件是任务范围的**唯一事实来源**。各模块 AGENTS.md 中的"范围与优先级"章节是它的摘要版本。
> **当前阶段：只做 P0。P1/P2 未获明确许可前一律不得实现。**

## 分级原则

| 级别 | 含义 | 当前状态 |
|------|------|---------|
| **P0 必做 Core** | 课程硬性要求，缺一不可 | ✅ **本阶段唯一允许实现的内容** |
| **P1 进阶 Advanced** | 加分项，隐藏测试考察点 | ⏸ 暂缓——P0 全部完成且测试全绿后，经确认再启动 |
| **P2 扩展 Extension** | 超出课程要求 | 🚫 **本课程不做**，除非老师明确要求 |

## P0 必做（Core）

| # | 任务 | 落点模块 | 验收方式 |
|---|------|---------|---------|
| 1 | Lexer + Token 位置 | compiler/lexer | 输出 `[种别码，词素值，行号，列号]` |
| 2 | 四类 SQL 语句 | compiler/parser | CREATE TABLE / INSERT / SELECT / DELETE |
| 3 | AST | compiler/parser | 四类语句均能构造语法树并打印 |
| 4 | Catalog | compiler/semantic | 表名/列名/列类型可维护、可导出 dict |
| 5 | 语义检查 | compiler/semantic | 存在性 / 类型一致性 / 列数列序 |
| 6 | Logical Plan | compiler/planner | CreateTable / Insert / SeqScan / Filter / Project / Delete |
| 7 | 错误定位 | compiler 全链路 | `[错误类型，位置，原因说明]` |
| 8 | 基础测试 | tests/ | 正常语句 + 错误语句均有用例且全绿 |

### P0 的功能边界（重要）

- **WHERE 只支持单个条件**：`列 比较符 值`（如 `age > 18`、`id = 1`、`name = 'Alice'`）
  - 比较符集合：`= <> != < <= > >=`
  - 两侧只能是"列引用"或"字面量"，**不支持** AND/OR/NOT、算术运算、嵌套括号、函数调用
- **SELECT 只支持单表**：不支持 JOIN、子查询
- **INSERT 支持一次多值**：`VALUES (...),(...)` 属于 P0（课程 `INSERT` 基础要求内）
- **不做任何优化**：计划按标准形状直接生成，谓词下推、常量折叠等一律不做

## P1 进阶（Advanced）—— 暂缓

- [ ] AND / OR / NOT 逻辑组合
- [ ] 复杂表达式（算术运算 `+ - * /`、嵌套括号、优先级处理）
- [ ] ≥2 条优化规则（谓词下推、常量折叠、列裁剪）
- [ ] 更强的错误诊断（拼写纠错建议，如"是否指 student?"）
- [ ] 隐藏测试高通过率（针对性补全边界用例）
- [ ] Plan 可视化（图形化输出）

## P2 扩展（Extension）—— 本课程不做

- [ ] JOIN / GROUP BY / ORDER BY
- [ ] Fuzz Testing
- [ ] 规则优化框架
- [ ] 简单代价模型
- [ ] EXPLAIN
- [ ] 高级错误恢复（恐慌模式恢复、多错误一次性报告）

## 越界判定规则

1. 任何不在"P0 必做"表中的功能，默认**不允许实现**。
2. 若某功能属于 P1/P2，必须在设计文档与代码中**显式标注为自己的判断**，并经确认后才动手。
3. 宁可少做，不可多做：多余功能会增加出错面、拖累 P0 的稳定性与报告的一致性。
4. 若实现过程中发现某 P1 特性"顺手就能加"，**仍然不加**——先记入本文件 P1 清单，留待后续阶段。
